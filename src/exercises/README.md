# Упражнения-шаблоны (`src/exercises`)

Каждый тип экрана урока — своя папка: **один `.vue`** (и для ученика, и для правки на ветке урока) и **`.json`** (описание типа).
Плеер (`LessonPlayer.vue`) только даёт шаблону состояние и действия ученика. Правку даёт ветка урока (`LessonRail.vue`).
Значок в меню «Exercise» (`ExerciseMini.vue`) — тот же плеер с этим шаблоном, уменьшенный. Поменял шаблон — поменялись урок, правка и значок.

> Этот файл — инструкция и для человека, и для нейросети. Нейросети давай **этот README + файл упражнения**, тогда она правит правильно.

## Что где лежит

```
src/exercises/
  index.js              реестр: kind → { …json, view: компонент }
  ctx.js                связь шаблона с плеером (usePlay) и с правкой (useEdit)
  parts/                общие детали — одинаковые во всех типах
  intro/ choice/ tip/ pairs/ order/ speak/ gap/ answer/ odd/ sort/
    <Тип>.vue           разметка + логика правки + <style scoped>
    <тип>.json          kind, title, head, templates, fields, check, words, skills, min, shuffle, limits
  exercises.test.ts     тесты: вид, правка, значки, совпадение .json с lesson.ts
```

| Папка | Тип (`kind`) | Шаблоны меню (`templates`) |
|---|---|---|
| `intro` | Новое слово | `intro` |
| `choice` | Выбери ответ / Аудиотест | `choice`, `audiotest` |
| `tip` | Подсказка | `tip` |
| `pairs` | Пары | `pairs` |
| `order` | Собери фразу | `order` |
| `speak` | Повтори за диктором | `sayword` |
| `gap` | Заполни пропуск + книжные | `type`, `fill`, `translate`, `bkword`, `brackets`, `bkpick`, `bkpic`, `bkqa` (+ `pg_…`) |
| `answer` | Ответь на вопрос | `answer`, `bkfree` (+ `pg_bkfree`) |
| `odd` | Найди лишнее | `odd` (+ `pg_odd`) |
| `sort` | Распредели / Заполни таблицу (`tw`) | `sort` (+ `pg_sort`) |
| `mf` | Красный Мерфи: объяснение A–D (`mode: 'info'`) и упражнения как в English Grammar in Use — поля в `mf/data.ts` | `mfinfo`, `mf171`, `mf25`, `mf112`, `mf51`, `mf395`, `mf212`, `mf314`, `mf43`, `mf31`, `mf15`, `mf193` |

`pg_…` — вкладка «Как в учебнике»: тот же экран с `step.bs === 'page'`. Книжные (Настины) — `step.bk` (список заданий — `BOOK` в `utils/lesson.ts`).

## Как устроен шаблон

```vue
<script setup>
import ExHead from '../parts/ExHead.vue'
import { usePlay, useEdit } from '../ctx'
import J from './мой.json'
const props = defineProps({ step: { type: Object, required: true }, part: { type: String, default: 'body' } })
const p = usePlay(), ed = useEdit()
</script>

<template>
  <template v-if="part === 'body'">       <!-- сам экран: и у ученика, и в правке (p.edit) -->
    <ExHead :step="step" :def="J.head" />
    …
  </template>
  <template v-else-if="part === 'fb' && p.st.done">   <!-- строка в подвале после ответа: «Верно!» / «Правильный ответ: …» -->
    <b>{{ p.right ? 'Верно!' : 'Правильный ответ:' }}</b><span class="fs">…</span><small v-if="p.later" class="lt">Вернёмся к этому в конце урока</small>
  </template>
  <template v-else-if="part === 'tools'"> <!-- кнопки в подвале правки, рядом с «Сохранить» -->
    <ExTool @click="…">＋ Строка</ExTool>
  </template>
</template>

<style scoped> … только для этого типа … </style>
```

- **`step`** — данные экрана. В правке их меняют прямо (`step.word = …`, `v-model="step.word"`) и зовут `ed.changed()` (детали `Ex*` зовут сами).
- **`part`** — какой кусок рисовать: `body` (экран), `fb` (строка ответа в подвале), `tools` (кнопки подвала правки).
- **Корень `body` — несколько элементов подряд (фрагмент)**: они встают прямо в колонку `.body` плеера (gap 14px). Не оборачивай всё в один div без нужды.

### Что даёт плеер — `const p = usePlay()`

| Поле | Что это |
|---|---|
| `p.edit` | `true` — правка на ветке (показывай поля вместо текста, тех же размеров) |
| `p.single`, `p.embedded`, `p.track` | просмотр одного экрана / экран на ветке / ученик проходит урок |
| `p.st` | состояние экрана: `done`, `picked`, `res`, `order` (порядок вариантов), `L`/`R`/`matched`/`bad`/`left`/`right` (пары), `pool`/`built` (собери фразу), `typed`/`tys` (вписанное), `mode`/`text`/`hint` (ответ на вопрос), `showTr`, `place`/`sel`/`tw`/`twr` (распредели, таблица) |
| `p.right`, `p.later`, `p.answer` | ответ верный / ошибка → вернёмся в конце урока / верный вариант (`opts[ans]`) |
| `p.src(ref, 'image' \| 'audio' \| 'video')` | адрес файла для `<img>` / `<audio>` / `<video>` |
| `p.say(ref)` | проиграть звук |
| Действия ученика | `p.pick(k)` выбор · `p.tap('left'\|'right', k)` пары · `p.put(k)` / `p.back(k)` собери фразу · `p.fill(k)` / `p.check()` / `p.gapOkAt(x)` пропуск · `p.sendText()` письменный ответ · `p.sortPick(k)` / `p.sortPut(col)` / `p.sortBack(k)` / `p.sortOkAt(k)` распредели · `p.rec`, `p.said`, `p.recToggle()`, `p.again()`, `p.setVid(el)` голос и видео · `p.favKey`, `p.favOn`, `p.favToggle()` закладка |

**Проверка ответа — в плеере**, не в шаблоне: какой тип как засчитывается (`verdict`, `checks`, `needCheck`, `canCheck`, `checkAny`) и что уходит в Review — `LessonPlayer.vue`. В `.json` поле `check` описывает это словами: `none` (сразу, без оценки), `tap` (тап — сразу ответ), `button` («Проверить»), `voice` (голос), `free` (без проверки).

### Что даёт правка — `const ed = useEdit()` (в уроке у ученика — заглушки)

| Поле | Что это |
|---|---|
| `ed.changed()` | данные экрана поменялись — сохранить |
| `ed.pick(step, ['image','video','audio'], opt?, field?)` | выбрать файл (opt — номер варианта/строки, field — поле, например `exAudio`) |
| `ed.drop(event, step, kinds, opt?, field?)` | файл перетащили сюда |
| `ed.clear(obj, field)` | убрать файл |
| `ed.pct(step, field, opt?)` | % загрузки файла или `null` |
| `ed.cards(step, 'intro' \| 'opts' \| 'pairs')` | открыть «Из карточек» (колоды) |
| `ed.canUndo(step)`, `ed.undoCard(step)` | «Другая карточка» / «↺» у «Нового слова» |
| `ed.dropFiles([refs])` | удалить свои файлы (убрали вариант с фото) |

### Общие детали — `parts/`

| Деталь | Что делает | Главное |
|---|---|---|
| `ExHead` | задание вверху экрана | `:step`, `:def` (задание по умолчанию); в правке — поле на том же месте |
| `ExMedia` | видео или фото 16:9, звук плашкой поверх | `:kinds`, `joined` (снизу блок — нижние углы прямые), `xm` (отступ снизу), `ph` (надпись пустого окна в правке; пусто — окна нет), `:audio` (`true` или `{ src, auto, add }`), `autoplay`, `:controls`, `vpill` (плашка управляет видео), `:vref`, `@vclick`, slot — своё поверх |
| `ExAudio` | синяя плашка звука; в правке — «Заменить» / «✕» / «＋ Аудио» | `:step`, `field`, `src`, `auto` (без своего — звук верного ответа), `add`, `at`: `row` (строкой) / `over` (поверх фото) / `plain` |
| `ExText` | текст; в правке — поле в том же теге | `v-model`, `tag` (`b`, `span`, `p`…), `ph`, `multi`, `empty`; slot — свой вид у ученика, slot `before` — что перед полем в правке |
| `ExRich` | текст с **жирным** (`**так**`) | `v-model`, `tag`, `ph`; в правке — выделил слово, «B» |
| `ExSay` | динамик перед текстом (озвучка строки) | `:step`, `:obj`, `field`, `:opt` |
| `ExTool` | маленькая кнопка подвала правки | `deck`, `un`, `on` |
| `ExPop` | кнопка подвала с окошком-полем (перевод, пояснение) | `v-model`, `label`, `hint`, `ph`, `multi`, `done`; slot — своё над полем |

## Правила (чтобы вёрстка не ехала)

1. **Правка того же размера, что вид ученика.** Текст → `ExText` (поле в том же теге и шрифте). Своё поле — `class="exf"` (голубая подложка, без рамки). Ничего не добавлять в поток экрана только для правки — окно вырастет.
2. **Кнопки правки** — только в `part="tools"` (подвал) или поверх (`position: absolute`, видны при наведении).
3. **Без пунктирных рамок** в правке — только голубая подложка `exf`.
4. **Стили — в `<style scoped>` своего файла.** Не `style="…"` в разметке и не `theme.css`. Поправить деталь только в своём типе — `:deep(.класс)`. Глобальные классы — только с приставкой `ex-` (`parts/ex.css`).
5. **Режимы экрана** в CSS — по классам предков: `.lp.book …` (Настины книжные), `.lp.book.bkpg …` («Как в учебнике»), `@media (min-width: 900px) { .lp:not(.embedded):not(.single) … }` (во весь экран на компьютере).
6. **Цвета** — только наши: тег-цвета навыков (L `#1cb0f6`, R `#a560e8`, W `#ff9600`, S `#58cc02`), `var(--blue)`, зелёный `#1fbe78` / `#8ff0c8`, красный `var(--red)` / `var(--red-l)`, у книжных — как в учебнике.

## Как добавить упражнение

### А. Новый вариант существующего типа (чаще всего)
Например, ещё одно задание из учебника, где ученик тоже вписывает слово (`gap`), выбирает (`choice`) и т.д.

1. **`utils/lesson.ts` → `TEMPLATES`**: `{ id: 'мой', kind: 'gap', t: 'Название', d: 'описание', make: () => ({ …«рыба»… }) }`. «Рыба» — готовый экран-образец (картинки — `fish('файл.jpg')` из `public/fish/`).
   Книжный — ещё строка в `BOOK` (`n` — номер в учебнике, `en` — задание по-английски); тогда он сам появится и во вкладке «Как в учебнике».
2. **`utils/lesson.ts` → `SKILLS`**: `мой: ['W']` — навыки (по первому плитка встаёт в группу меню).
3. **Шаблон**: если вид другой — ветка в `<Тип>.vue` по `step.bk` / своему полю (`v-if`), и стили там же.
4. **`<тип>.json`**: id в `templates`, навыки в `skills` (тест сверяет с `lesson.ts`). У книжного — и `pg_<id>`: его «Как в учебнике» `lesson.ts` добавляет в `TEMPLATES` сам.
5. Новые поля данных — см. «Сервер» ниже.

### Б. Совсем новый тип (новый `kind`)
1. Папка `src/exercises/мой/` с `Мой.vue` и `мой.json` (скопируй самый похожий тип).
2. `index.js`: import и строка в `EX`.
3. `utils/lesson.ts`: `StepKind`, `KINDS` (название, описание, цвет, значок, задание по умолчанию), `KIND_MIN`, `newStep`, `fishStep`, `TEMPLATES`, `SKILLS`, `stepIssue` (когда экран «не заполнен»), слова для Review (`words`, если есть).
4. `components/LessonPlayer.vue`: как засчитывается ответ — `setup()` (начальное состояние), `checks` / `needCheck` / `canCheck` / `checkAny`, запись в Review (`watch(() => st.done …)`).
5. **Сервер** (`server/courses.ts`): `STEP_KINDS` и поля типа.

### Сервер — важно
`server/courses.ts` → `step()` **сохраняет только известные поля** каждого типа, остальное молча выкидывает. Общие для всех: `head`, `image`, `audio`, `video`, `exAudio`, `bk`, `bs`, `bn`, `tn`, `td`, `min`. Новое поле (или новый `kind`) — добавить туда, иначе после сохранения курса оно пропадёт. Это единственное место, где нужен деплой сервера.

### Проверка
- `npm run dev` — правишь файл, экран обновляется за секунду (на телефоне в той же Wi-Fi: `npm run dev -- --host`).
- Смотри **оба режима**: экран на ветке урока и он же в правке (карандаш) — высота окна не должна меняться; и значок в меню «Exercise».
- `npm test` — `exercises.test.ts` проверяет вид, правку, значки и совпадение `.json` с `lesson.ts`. Добавь тест на свой тип по образцу.
