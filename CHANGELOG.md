## [Unreleased]
### Добавлено
- Расписание сохраняется в Firestore через сервер: отдельная сущность **урока** (`lessons`, в ней массив `studentIds` — под групповые занятия) и документы двух живых недель — текущей и следующей (`schedule/<понедельник>`, слоты «дата_час → урок»). Новые маршруты `GET /schedule`, `POST /lessons`, `POST /lessons/:id/move`, `POST /lessons/swap`, `DELETE /lessons/:id`; переменная `SCHEDULE_TZ`; тесты `server/schedule.test.mjs`.
- Ученик получает с сервера только свои уроки; архив ученика убирает его из уроков двух недель.
- Ученики через сервер (Firestore закрыт от сайта правилами): «+ Добавить ученика» (имя, уровень, пакет) → ссылка-приглашение (копировать / отправить в Telegram), статусы «Ждёт приглашения» / «В приложении», смена аккаунта, архив с закрытием доступа.
- Серверные тесты логики входа и учеников (`server/*.test.mjs`).
- Настоящая авторизация: сервер на Render (`server/`) проверяет подпись Telegram, выдаёт Firebase-токен; роли хранятся в Firestore.
- Вход в обычном браузере через «Войти через Telegram», кнопка «Выйти» в «Профиле».
- Приглашения учеников: «Пригласить в приложение» в карточке ученика → одноразовая ссылка.
- `.gitignore`, `.env.example`, `firestore.rules`.
### Изменено
- Сервер переведён на TypeScript. Все сущности (ученик, урок, неделя, приглашение, пользователь) описаны в одном файле `server/types.ts`; сборка `npm run build`, запуск `npm start` (`node dist/index.js`). **На Render нужно поменять Build на `npm install --include=dev && npm run build`.** Поведение сервера не менялось, тесты (`npm test`) прошли без правок логики.
- Фронт: ученики и уроки переехали в Pinia (`stores/students.ts`, `stores/schedule.ts`) и используют типы из `server/types.ts`; `useStudents.js` и `useSchedule.js` удалены, общий код Firebase и запросов — в `src/firebase.ts`. Поле `photo_url` у ученика и преподавателя стало `photoUrl` (как на сервере), id демо-учеников — строки. Добавлены `npm run typecheck` и `npm test` (vitest: сторы + дымовой тест всего приложения в демо-режиме).
- **Путь, пресеты, колоды слов и прогресс повторений теперь хранятся в Firestore** и не пропадают после перезагрузки. Новые коллекции `paths`, `presets`, `decks`, `srs`; новые маршруты сервера `GET /content`, `PUT /paths/:studentId`, `POST /paths/:studentId/complete`, `PUT|DELETE /presets/:id`, `PUT|DELETE /decks/:id`, `GET /srs`, `POST /srs/rate` (см. `server/README.md`). Сервер проверяет форму всех данных (`server/clean.ts`) и роль: ученик видит только свой путь и доступные колоды, может отметить лишь свой текущий кружок и пишет только свой прогресс; монеты за кружок начисляет сервер, один раз.
- Фронт: путь, колоды, повторения и загрузка контента — в Pinia (`stores/path.ts`, `decks.ts`, `srs.ts`, `content.ts`). Правки преподавателя сохраняются автоматически (`stores/sync.ts`): пауза ~0,7 с, отправляется только изменённое, запросы идут по очереди, при отказе сервера экран перечитывается. `store/mock.js` удалён: интерфейсное состояние и «вычисляемое про меня» — `store/app.ts`, демо-данные — `store/demo.ts` (подгружаются лениво и только в `npm run dev`), даты и функции над путём — `utils/`. `useSrs.js` стал `useSrs.ts`. Id записей теперь строки, которые придумывает сайт (`newId`), `v-model.number` у выбора пресета убран.
- **Нужно сделать на Render после обновления:** выкатить новую версию сервера (в `server/` появились `content.ts`, `srs.ts`, `clean.ts`, `access.ts`); переменные и настройки сборки те же. Правила Firestore менять не нужно — клиенты по-прежнему не имеют доступа к базе.
- Фронт: вход, роль и текущий ученик переехали в Pinia (`stores/auth.ts`); `useTelegramAuth.js` удалён, `state.role` и `state.currentStudentId` из `mock.js` убраны (теперь `auth.role` и `auth.currentStudentId`), `auth.teacher` стал `auth.isTeacher`, `setRole` — действие стора. Сброс вкладки при смене роли остался в `mock.js` (`linkStores`). Клеймы токена описаны типом `SessionClaims` в `server/types.ts`: его используют и сервер (при выдаче токена), и фронт (при чтении).
- Уроки на «Главной» больше не узлы пути ученика, а отдельные записи `state.lessons`; перетаскивание, перенос, обмен и снятие урока сохраняются на сервере (`useSchedule.js`), на экране — сразу, с откатом при ошибке.
- Текущий час в расписании подсвечивается красным полупрозрачным цветом (день, время и ячейка).
- Внизу «Профиля» только версия и коммит, без даты и времени сборки.
### Удалено
- Демо-ученики в боевой версии: они остались только в `npm run dev`.
- Заглушки `VITE_TEACHERS`, `VITE_BROWSER_USER`, `VITE_BROWSER_NAME`: роль и имя теперь приходят с сервера.
- Кнопка «Полный экран» / «Свернуть» (`FullscreenToggle.vue`, `useFullscreen.js`).

## [0.2.0] — 2026-10-25
### Добавлено
- Главная преподавателя: две таблицы расписания (часы 08:00–22:00), список учеников справа; ученика и урок можно перетаскивать мышью и касанием в любую ячейку, обмен уроков местами, снятие урока перетаскиванием на список, тосты с «Отменить».
- Подсветка текущего часа в верхней таблице: время, день недели и ячейка на пересечении.
- Вкладка «Путь» с пресетами; кружки трёх типов (ДЗ, повторение слов, слова + ДЗ), юниты можно добавлять, переименовывать, удалять.
- Вкладка «Слова» — мини-Anki для преподавателя и ученика; колоды по ссылке на Google Таблицу, назначение колод ученикам.
- Аватарки из Telegram; роль преподавателя без бэкенда через `VITE_TEACHERS`.
- Кнопка «Полный экран» для Telegram на компьютере.
- Версия, метка коммита и время сборки внизу «Профиля».
### Изменено
- Весь интерфейс в стиле Duolingo (цвета, объёмные кнопки, шрифт Nunito, тёмная тема).
- «Профиль» ученика: круг выученных слов и круг прогресса вместо «дней подряд» и монет.
### Удалено
- Логика прошлого времени и «проведённых» уроков на главной преподавателя.
