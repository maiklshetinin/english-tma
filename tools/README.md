# PDF домашки → JSON для «Ответа по смыслу»

`kp-json.py` (кнопка — `Сделать JSON.bat`) превращает PDF домашки Karta Polaka (курс Марии Кобрыни) в JSON. Этот JSON вставляют в редактор урока, и получаются экраны «Ответ по смыслу»: вопрос, эталонный ответ с выделениями, звёзды у обязательных вопросов.

## Установка (один раз)

1. Нужен Python 3. Проверить:
   ```
   python --version
   ```
   Если Python не найден, скачайте его с python.org. На новом Windows сработает и команда `py install`. При установке отметьте «Add Python to PATH».
2. Поставьте библиотеку для чтения PDF:
   ```
   pip install pymupdf
   ```
   Если `pip` не найден: `py -m pip install pymupdf`.

Библиотека ставится на компьютер, а не в проект. `package.json` и `node_modules` не меняются.

## Быстрый способ: одна кнопка на все упражнения

Все упражнения делает один скрипт — `make-json.py` (кнопка `Сделать JSON.bat`). Он спрашивает номер упражнения, и меняется только тип —
данные у всех одинаковые (24.11.2026). В JSON — только данные, без промптов и настроек:

```json
{ "type": "talkvn", "steps": [ { "text": "Jaka jest tradycyjna polska zupa?", "ideal": "Najbardziej popularna polska zupa to ==żurek==…", "star": true, "n": 2 } ] }
```

- `type` — ID упражнения: тот же, что серым тегом на плашке в меню Exercise;
- `text` — вопрос, `ideal` — эталон (с выделениями домашки), `star` — обязательный (★), `n` — номер в домашке.

Всё остальное — тип экрана и флаги, промпты, роль консула, модели — приложение берёт из шаблона упражнения и общих настроек курса
(«{ }» на плитке). Поменять промпт — там, а не в JSON.

| № | ID | Упражнение | Папка |
|---|---|---|---|
| 1 | `kp` | Ответ по смыслу | `json/мост/` |
| 2 | `kpapi` | Ответ по смыслу · Gemini API | `json/gemini-live/` |
| 3 | `kpfile` | Ответ по смыслу · целым аудио | `json/запись целиком/` |
| 4 | `kpball` | Ответ по смыслу · шар | `json/шар/` |
| 5 | `talk` | Разговор с Gemini | `json/разговор без персонажа/` |
| 6 | `talkava` | Разговор с персонажем | `json/разговор/` |
| 7 | `talkptt` | Разговор · рация | `json/рация/` |
| 8 | `talkptt2` | Разговор · рация (Busuu) | `json/рация busuu/` |
| 9 | `talkvn` | Рация · голосовые | `json/голосовые/` |
| 10 | `talkexam` | Собеседование · рация | `json/собеседование/` |

Новое упражнение — одна строка в `TYPES` в начале `make-json.py`.

Из терминала:
```
python tools/make-json.py --list                    # все типы
python tools/make-json.py talkvn                    # все PDF из tools/pdf/ → папка типа
python tools/make-json.py kpball "ДЗ 8.pdf"         # рядом появится «ДЗ 8.kpball.json»
python tools/make-json.py talkptt "json/мост/ДЗ 8. Кухня.json"   # можно из готового JSON
```

Старые скрипты (`kpapi-json.py`, `kpfile-json.py`, `talk-json.py`, `ptt-json.py`, `exam-json.py`) и их кнопки больше не нужны — их можно удалить.
`kp-json.py` оставить: им `make-json.py` разбирает PDF.

1. Положите PDF домашек в папку `tools/pdf/` (можно несколько сразу).
2. Дважды щёлкните нужную кнопку.
3. Откроется окно: по каждому файлу будет написано «Готово…» с отчётом или «Не получилось…» с причиной. Окно закроется, когда нажмёте любую клавишу.
4. Готовые JSON лежат в папке этой кнопки, имена такие же, как у PDF. Вставляют так: скопировать весь текст файла и Ctrl+V на холсте урока.

PDF разбирает только `kp-json.py`; остальные скрипты его запускают, поэтому вопросы, эталоны и звёзды везде одинаковые.
Промпты в JSON уроков не пишутся: у экранов — умолчания своего упражнения, их видно и можно поменять на вкладке JSON экрана («{ }»).

Содержимое папок `pdf/` и `json/` в git не попадает, это материалы курса. Сами папки при этом остаются в проекте.

### Разговор и рация

- Роль Gemini — до 4000 знаков (столько хранит сервер). Слишком длинный эталон сокращается — в отчёте видно, у каких вопросов.
- Задание на экране — «Вопрос N ★: … — поговорите с консулом по-польски» (★ — обязательный).
- Без персонажа — `--no-avatar` (у обоих скриптов).
- Из терминала: `python tools/talk-json.py "ДЗ 8. Кухня.pdf"` (рядом — `ДЗ 8. Кухня.разговор.json`), `python tools/ptt-json.py "ДЗ 8. Кухня.pdf"` (рядом — `ДЗ 8. Кухня.рация.json`). Можно и из готового JSON «моста».
- `python tools/kpfile-json.py "ДЗ 8. Кухня.pdf"` — рядом `ДЗ 8. Кухня.запись.json`. Пишет сразу экраны (`steps`), а не `questions`: в формате `questions` поле `dic` приложение не читает. Можно и из готового JSON «моста».
- `python tools/exam-json.py "ДЗ 8. Кухня.pdf"` — рядом `ДЗ 8. Кухня.собеседование.json` («Собеседование · рация»). Роль консула в JSON не пишется — общий шаблон упражнения; поменять для всех экранов — «{ }» на плитке «Собеседование · рация» (вкладка Karta Polaka). `--no-avatar` — без персонажа.
- `python tools/kpapi-json.py "ДЗ 6. Пасха.pdf"` — рядом `ДЗ 6. Пасха.gemini.json`; `--model auto` — проверка текстовой Flash Lite вместо голосовой Live.

## Как пользоваться из терминала

1. Откройте терминал в папке проекта (например, в VS Code: Terminal → New Terminal).
2. Запустите скрипт с путём к PDF:
   ```
   python tools/kp-json.py "C:\Users\User\Downloads\ДЗ 6. Пасха.pdf"
   ```
3. Рядом с PDF появится JSON с тем же именем (`ДЗ 6. Пасха.json`), а в терминале — короткий отчёт:
   ```
   Готово: C:\Users\User\Downloads\ДЗ 6. Пасха.json
     Урок 6. Период Пасхи · вопросов: 18 · со звездой: 16 (1, 4, 5, …)
     заметок Марии: 1 · дополнение: есть
   ```
4. Откройте урок в редакторе и вставьте содержимое JSON: скопируйте весь текст файла и нажмите Ctrl+V на холсте.

## Дополнительно

- **Сохранить в другое место:** `-o путь.json`
  ```
  python tools/kp-json.py "ДЗ 7.pdf" -o "C:\Users\User\Desktop\урок7.json"
  ```
- **Под Gemini API** — свой скрипт:
  ```
  python tools/kpapi-json.py "ДЗ 7.pdf"
  ```
- **Задать название урока вручную,** если скрипт его не нашёл (в отчёте будет подсказка):
  ```
  python tools/kp-json.py "ДЗ 5.pdf" --lesson "Урок 5. Период рождества"
  ```

## Что попадает в JSON

| Поле | Что это |
|---|---|
| `questions[].question` | вопрос из задания (первая страница) |
| `questions[].star` | `true` — у вопроса красная звезда, ответ знать обязательно |
| `questions[].reference` | эталонный ответ простым текстом; пункты списка начинаются с «• » |
| `questions[].reference_html` | эталон с оформлением, его берёт приложение: оранжевые термины, жирный, красный, курсив, абзацы, списки |
| `questions[].reference_md` | эталон с `**жирным**` |
| `questions[].notes` | заметки Марии по-русски (📌 и советы); в эталон не попадают |
| `questions[].question_in_answers` | вопрос так, как он написан в «Ответах», если он отличается от задания |
| `appendix` | «Дополнение»: первые строки песен или колядок |
| `pass_threshold` | порог зачёта, 60 % |
| `engine`, `model` | только в `json/gemini-live/`: `"api"` и `"live"` — экраны «· Gemini API» с проверкой Live-моделью (можно задать и у отдельного вопроса) |

## Если что-то не так

Скрипт не выдаёт кривой JSON молча, а пишет, что не так:

- **«Нет файла»** — проверьте путь; если в имени есть пробелы, путь нужно взять в кавычки.
- **«не нашёл страницу с заданием («Ответьте…»)»** или **«не нашёл страницу «Ответы»»** — это не домашка курса или у неё другая структура.
- **«в ответах нашёл вопросы …, а в задании их …»** — вопрос в ответах разбит или пропущен.

В последних двух случаях отправьте PDF Claude, чтобы подстроить разбор под новое оформление.
